# Vercel Study Guide

## Goals
1. Understand the core components of Vercel
2. Ship a feature end-to-end: GitHub → Vercel web app

## Modules

| # | Module | Focus |
|---|--------|-------|
| 1 | [Core Concepts](./01-core-concepts.md) | Platform overview, key primitives |
| 2 | [Project Configuration](./02-project-configuration.md) | `vercel.json`, env vars, build settings |
| 3 | [GitHub Integration](./03-github-integration.md) | Connecting repos, deploy hooks, preview deployments |
| 4 | [End-to-End Feature Shipping](./04-e2e-feature-shipping.md) | Full workflow: branch → PR → preview → merge → production |
| 5 | [Functions & Edge](./05-functions-and-edge.md) | Serverless functions, edge middleware, runtimes |
| 6 | [Hands-on Exercises](./06-exercises.md) | Practice tasks to reinforce each module |

## Suggested Order
Work through modules 1 → 4 in order. Modules 5 and 6 can be done in parallel with 3–4 as you build.

## Time Estimate
- Modules 1–2: ~1–2 hours (reading + tinkering)
- Modules 3–4: ~2–3 hours (hands-on)
- Module 5: ~1–2 hours
- Module 6: ~1–2 hours (exercises)
